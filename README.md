F130 DC-Motor 3d Vector control project

Files are made with 0.3mm tolerance from standardized Typ-F130 DC Motor in Autodesk Fusion.
<br>
The Motor holder itself is avalible with a balljoint attachment or without.
<br>
The balljoints radius is 5mm and the enterance is 3.8mm in width. To keep it flexible i've added gaps with 1mm width.
